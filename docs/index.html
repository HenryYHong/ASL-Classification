How it works

MediaPipe finds 21 hand landmarks; a random forest reads the handshape; a state machine decides when a letter was actually signed. J and Z are motion letters, so they need a launch pose held still, then the stroke.

Trained on one signer across three sessions: 0.769 on held-out sessions for the static letters, 0.889 for J and Z. Accuracy varies with hand shape and lighting, and M, N and S are the least reliable.
